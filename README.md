# Mini-Firmennetzwerk

Ein virtuelles Firmennetzwerk, das ich Schritt für Schritt aufbaue und dokumentiere,
um Systemintegration praktisch zu lernen.

## Geplant
- Linux-Server (Ubuntu Server) in VirtualBox
- DHCP und DNS
- Client-VM und Netzwerkanalyse mit Wireshark
- Firewall (OPNsense) und getrennte Netze
- Netzwerkdiagramm und Dokumentation

**Status:** Phase 1 in Arbeit

## English
A virtual company network I build and document step by step to learn
systems integration hands-on.
